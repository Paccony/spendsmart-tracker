# SpendSmart Tracker

Smart expense tracking app with multi-language support (Montenegrin, Serbian, English, German)

## Features

- 📊 Track daily, weekly, and monthly expenses
- 🎯 Set category budgets and track spending limits
- 🤖 Local AI analysis (no API key needed)
- 🌍 4 languages: Montenegrin, Serbian, English, German
- 💾 Data stays in your browser (localStorage)
- 📥 Export expenses to CSV
- 📈 Charts for visual insights (weekly trends, category breakdown)

## How to Use

1. **Add expenses** - Click "New Expense" button
2. **Track spending** - View breakdown by category
3. **Set budgets** - Control spending in each category
4. **Get AI insights** - Smart saving tips based on your actual spending
5. **Export data** - Download CSV for personal records

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- Chart.js for data visualization
- LocalStorage for persistence
- Fully responsive design
